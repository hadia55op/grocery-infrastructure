# Grocery Infrastructure

Infrastructure and DevOps configuration for the Online Grocery Store microservices application.

## Technology Stack

* Docker
* Docker Compose
* Kubernetes (k3s)
* GitHub Actions
* GitHub Container Registry (GHCR)
* Traefik
* cert-manager
* Backblaze B2

## Responsibilities

* Docker Compose configuration
* Kubernetes manifests
* Application deployments
* Service configuration
* Ingress and DNS
* HTTPS configuration
* CI/CD workflows
* Database backup automation
* Deployment documentation

## Development

Infrastructure configuration and deployment instructions will be added throughout the project.
